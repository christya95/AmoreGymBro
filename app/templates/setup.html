Start with 1Password

The app needs its password and session secret from the AmoreGymBro vault at launch. Do not paste keys into chat or this page.

Mac development startup
  1. Unlock 1Password and make sure the AmoreGymBro vault is available.
  2. From the project folder on this Mac, run ./start-local.sh. It uses op run with .env.app.references, a file containing references only, to supply credentials at launch.
  3. Open the sign-in page using your app password from 1Password.

OpenAI API usage is billed separately from a ChatGPT subscription.

Configuration & sync details

The local .env file is for ordinary configuration, such as display and sync settings. Secret values are supplied at launch.

APP_PASSWORD needs at least 10 characters and APP_SECRET at least 16. HEVY_API_KEY enables read-only sync; OPENAI_API_KEY enables Professor Zeus. Store their values in 1Password.

Leave HEVY_WEBHOOK_AUTHORIZATION unset and Hevy callbacks disabled. A callback URL is not needed for sync.
